# 番茄钟功能优化设计文档

**日期**: 2026-02-21  
**版本**: v1.0  
**状态: 设计确认

## 概述

优化番茄钟专注计时功能，采用渐进式开发策略，分三个阶段：

| Phase | 内容 | 预计工作量 |
|-------|------|-----------|
| Phase 1 | 时长预设 + 全屏模式 | 小 |
| Phase 2 | 白噪音系统 | 中 |
| Phase 3 | 统计报表增强 | 大 |

---

## Phase 1: 时长预设 + 全屏模式

### 1.1 时长预设选项

**UI 位置**: 模式切换按钮下方，折叠面板形式

**预设值**:
```
专注时长: [5分钟] [15分钟] [25分钟✓] [45分钟]
短休息:   [1分钟] [3分钟] [5分钟✓]
长休息:   [5分钟] [10分钟] [15分钟✓]
```

**默认值**: 专注25分钟、短休息5分钟、长休息15分钟

**数据结构**:
```javascript
const durationPresets = {
  work: [5, 15, 25, 45],
  shortBreak: [1, 3, 5],
  longBreak: [5, 10, 15]
}

const selectedDurations = ref({
  work: 25,
  shortBreak: 5,
  longBreak: 15
})
```

**改动文件**:
- `frontend/src/stores/focusStore.js` - 添加预设配置和状态
- `frontend/src/views/FocusView.vue` - 添加设置面板UI组件

### 1.2 全屏模式

**功能要点**:
- 全屏按钮位于控制栏（音效按钮右侧）
- 使用浏览器 Fullscreen API
- 全屏时：计时器居中放大、隐藏导航、暗色背景
- ESC 键退出全屏

**改动文件**:
- `frontend/src/views/FocusView.vue` - 添加全屏按钮和全屏样式

## Phase 2: 白噪音系统

### 2.1 音效类型

| 类别 | 音效名称 | 实现方式 |
|------|----------|----------|
| 自然 | 雨声 | 棕噪音 + 滤波 |
| 自然 | 森林鸟鸣 | 粉噪音 + 调制 |
| 自然 | 海浪 | 低频噪音 + 包络 |
| 自然 | 篝火 | 噪音 + 爆裂调制 |
| 环境 | 咖啡店 | 多层噪音混合 |
| 环境 | 图书馆 | 低音量白噪音 |
| 环境 | 风扇声 | 稳定白噪音 |

### 2.2 UI 设计

```
┌─────────────────────────────────┐
│ 🎵 背景音                        │
│ ├─ ☔ 雨声      ━━━━━○ 音量 60%  │
│ ├─ 🌲 森林     ─────○           │
│ ├─ 🌊 海浪     ─────○           │
│ ├─ ☕ 咖啡店   ─────○           │
│ └─ 📚 图书馆   ─────○           │
│                                  │
│ ☐ 专注时自动播放                 │
└─────────────────────────────────┘
```

**功能要点**:
- 每种音效独立音量控制 (0-100%)
- 支持多音效混合播放
- 可设置"专注时自动播放"
- 休息时可选暂停或继续

### 2.3 技术实现

使用 **Web Audio API** 程序化生成，无需外部音频文件：
- 基础噪音：白噪音/粉噪音/棕噪音
- 滤波器：低通/高通/带通模拟不同质感
- 调制：LFO调制模拟自然变化

**新增文件**:
- `frontend/src/utils/soundGenerator.js` - 音效生成器

**改动文件**:
- `frontend/src/stores/focusStore.js` - 音效管理器扩展
- `frontend/src/views/FocusView.vue` - 音效选择UI

## 风险与注意事项

1. **浏览器兼容性**: Fullscreen API 在移动端支持有限
2. **音频自动播放**: 需要用户交互后才能播放，需要处理自动播放策略
3. **性能**: 白噪音混合时注意 CPU 占用
4. **数据持久化**: 用户设置需要持久化到 localStorage 或后端
